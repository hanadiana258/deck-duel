Deck Duel: an original card battler you play in the browser. Spend mana, play attack, guard and heal cards from a five-card hand, and outlast The Arcanist — an AI opponent that heals when low and swings when you are open. Title screen, readable cards, HP bars, win and loss screens. Keyboard (N) and mouse.

## Run it

```sh
node main.ts        # hand the game in (MAKEFUN_OUTPUT_DIR=out locally)
node serve.ts       # or play it: http://localhost:8080
```
